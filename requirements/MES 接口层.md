# MES 接口层 MES Interface Layer

## 1. 文档说明

### 1.1 文档目的

MES 接口层负责与 MES 系统进行任务、校验、结果和异常信息交互。

MES 接口层应支持 MES 任务获取、任务解析、装货前校验、取货前校验、任务完成回传、异常回传，以及 OP 信息、扫码信息、格口信息、物料信息和操作结果的标准化回传。

本文档用于说明 MES 接口层在需求阶段需要具备的接口能力、数据对象、交互流程、异常处理和追溯要求，不描述具体接口协议、字段长度、鉴权方式或报文格式。

### 1.2 职责边界

MES 接口层负责“和 MES 说什么、什么时候说、结果怎么转成系统可用信息”。

简单来说：

- MES 负责“提供生产任务、物料需求、工单和业务校验规则”。
- MES 接口层负责“获取任务、解析任务、调用校验、回传结果和异常”。
- 任务管理层负责“把 MES 任务转换为系统任务并维护生命周期”。
- 站点作业层负责“在装货、取货前调用 MES 校验并按结果执行现场作业”。
- 日志与追溯层负责“记录 MES 请求、响应和业务影响”。

MES 接口层不直接创建现场作业会话，不直接开格口，不直接决定 OP 是否可以绕过校验。是否允许人工放行应由流程模板、站点作业层和权限控制共同决定。

### 1.3 一期建设原则

一期 MES 接口层应优先保证任务闭环和关键追溯字段完整。

一期至少应支持：

- 从 MES 获取待执行任务。
- 将 MES 任务解析为系统任务和任务明细。
- 装货前向 MES 校验物料、批次、工单、OP 和站点。
- 取货前向 MES 校验领料资格、物料、任务和 OP。
- 完成后向 MES 回传任务结果。
- 异常时向 MES 回传异常原因和当前处理状态。
- 回传 OP 编号、OP 名称、操作类型、操作时间、站点、格口、物料、扫码结果等信息。

## 2. 控制对象

### 2.1 MES 任务 MES Task

MES 任务是由 MES 下发或供本系统拉取的业务任务来源。

MES 任务至少应包含：

- MES 任务编号。
- 工单号。
- 任务类型。
- 业务场景，例如发料、配送、收料、退料。
- 物料明细。
- 起始站点。
- 目标站点或目标设备。
- 要求完成时间，如果有。
- 指定 OP 或班组，如果有。
- MES 扩展字段。

MES 任务进入本系统后，应保留原始 MES 任务编号和原始报文摘要，便于后续追溯。

### 2.2 MES 任务明细 MES Task Detail

MES 任务明细表示任务中具体物料、数量、批次和目标信息。

任务明细至少应包含：

- 明细编号。
- 关联 MES 任务编号。
- 物料编码。
- 物料名称。
- 物料类型。
- 数量。
- 单位。
- 批次号。
- 工单号。
- 来源站点。
- 目标站点。
- 指定格口，如果有。
- 指定领货 OP，如果有。
- MES 扩展字段。

MES 明细解析后应与任务管理层的任务明细建立关联关系。

### 2.3 MES 校验请求 MES Validation Request

MES 校验请求用于在装货、取货或完成前向 MES 确认当前操作是否允许继续。

校验请求至少应包含：

- 系统任务编号。
- MES 任务编号。
- 校验类型，例如装货前校验、取货前校验、完成前校验。
- 当前站点。
- 当前复合机器人编号。
- 当前发货柜编号。
- 当前格口编号。
- OP 信息。
- 扫码信息。
- 物料信息。
- 操作时间。

### 2.4 OP 回传信息 OP Report Info

OP 回传信息是 MES 接口层必须重点保证完整性的追溯字段。

OP 回传信息至少应包含：

- OP 编号。
- OP 名称。
- OP 所属班组或部门，如果有。
- OP 角色或权限类型。
- 操作类型，例如装货、取货、确认、人工放行、异常处理。
- 操作站点。
- 操作格口。
- 操作时间。
- 认证方式，例如账号、刷卡、扫码、人脸或人工选择。
- 是否代操作。
- 授权人，如果发生主管或管理员放行。

若现场只有 OP 编号，系统也应尽量从基础数据层补全 OP 名称、班组和角色后再回传 MES。

### 2.5 MES 回传结果 MES Report Result

MES 回传结果表示本系统向 MES 提交后的接口处理结果。

回传结果至少应记录：

- 回传业务类型。
- 关联系统任务编号。
- 关联 MES 任务编号。
- 请求时间。
- 响应时间。
- 回传状态。
- MES 返回码。
- MES 返回消息。
- 是否需要重试。

## 3. 接口能力需求

### 3.1 MES 任务获取

系统应支持从 MES 获取待执行任务。

任务获取方式可包括：

- 系统定时拉取。
- MES 主动推送。
- 人工触发同步。

无论采用哪种方式，系统均应保证 MES 任务编号不重复创建。重复任务应识别为已存在任务，并根据业务规则忽略、更新或提示人工处理。

### 3.2 任务解析与转换

MES 接口层应将 MES 原始任务解析为任务管理层可使用的统一任务模型。

解析内容至少包括：

- 任务类型。
- 业务运行模式。
- 物料明细。
- 起始站点和目标站点。
- 物料类型。
- 工单、批次和数量。
- 是否需要 OP 绑定。
- 是否需要 MES 强校验。
- 流程模板匹配所需条件。

解析失败时，不得创建可执行任务，应生成接口异常记录并提示人工处理。

### 3.3 装货前校验

装货前校验用于确认 OP 在指定站点、指定任务、指定物料和指定格口执行装货是否被 MES 允许。

装货前校验请求应至少携带：

- MES 任务编号。
- 系统任务编号。
- 当前站点。
- 装货 OP 信息。
- 物料编码。
- 批次号。
- 工单号。
- 扫码内容。
- 目标格口。
- 操作时间。

MES 返回不允许时，站点作业层不得继续开锁或完成装货确认，除非流程模板明确允许主管或管理员人工放行。

### 3.4 取货前校验

取货前校验用于确认当前 OP 是否允许领取指定格口内的指定物料。

取货前校验请求应至少携带：

- MES 任务编号。
- 系统任务编号。
- 当前站点。
- 取货 OP 信息。
- 物料编码。
- 批次号。
- 工单号。
- 格口编号。
- 取货凭证或扫码内容，如果有。
- 操作时间。

若 MES 返回 OP 不匹配、物料不匹配、任务已关闭或工单状态异常，应阻止普通取货，并展示明确原因。

### 3.5 完成回传

任务或任务明细完成后，系统应向 MES 回传完成结果。

完成回传至少应包含：

- MES 任务编号。
- 系统任务编号。
- 任务明细编号。
- 完成状态。
- 完成数量。
- 物料编码。
- 批次号。
- 工单号。
- 站点编号。
- 格口编号。
- OP 回传信息。
- 扫码信息。
- 完成时间。

完成回传失败时，系统应保留待回传记录并支持重试，不应丢失本地任务完成事实。

### 3.6 异常回传

发生业务异常、硬件异常、RCS 异常、MES 校验失败、人工放行或任务关闭时，系统应根据配置向 MES 回传异常信息。

异常回传至少应包含：

- MES 任务编号。
- 系统任务编号。
- 异常类型。
- 异常原因。
- 当前任务状态。
- 当前站点。
- 当前格口。
- 当前 OP 信息，如果有。
- 处理方式。
- 处理人。
- 处理时间。

## 4. 状态定义

### 4.1 MES 任务同步状态

建议状态包括：

- 未同步。
- 已获取。
- 已解析。
- 解析失败。
- 已创建系统任务。
- 已忽略。
- 异常待处理。

### 4.2 MES 校验状态

建议状态包括：

- 未校验。
- 校验中。
- 校验通过。
- 校验拒绝。
- 校验超时。
- 接口异常。
- 人工放行。

### 4.3 MES 回传状态

建议状态包括：

- 待回传。
- 回传中。
- 回传成功。
- 回传失败。
- 等待重试。
- 人工关闭。

回传失败不得直接覆盖任务完成状态，应区分“本地业务已完成”和“MES 回传未成功”。

## 5. 异常处理

### 5.1 MES 通信异常

MES 通信异常时，系统应根据流程模板判断是否允许离线作业。

若为 MES 强校验流程，通信异常时不得继续关键业务操作。

若允许离线作业，应记录离线原因、操作人、授权人和待补传数据。

### 5.2 MES 校验拒绝

MES 校验拒绝时，应阻止当前业务动作，并显示 MES 返回原因。

常见拒绝原因包括：

- OP 无权限。
- 工单状态不允许。
- 物料不匹配。
- 批次不匹配。
- 任务已完成或取消。
- 当前站点不匹配。

### 5.3 回传失败与重试

完成回传或异常回传失败时，系统应支持自动重试和人工重试。

重试时应保证同一业务结果不会在 MES 侧重复记账或重复完成。幂等标识应由 MES 任务编号、系统任务编号、任务明细编号和操作流水号共同确定。

## 6. 日志与追溯

MES 接口层应记录：

- MES 任务获取日志。
- MES 原始任务摘要。
- 任务解析结果。
- 装货前校验请求与响应。
- 取货前校验请求与响应。
- 完成回传请求与响应。
- 异常回传请求与响应。
- OP 回传字段快照。
- 接口异常、超时、重试和人工关闭记录。

日志中涉及敏感字段时，应满足现场信息安全要求。用于排查问题的报文摘要应能够关联到完整业务任务和 OP 操作记录。
