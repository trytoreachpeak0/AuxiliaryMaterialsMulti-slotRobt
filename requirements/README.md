# 需求目录说明

## 推荐阅读顺序

当前需求按版本拆分：

| 目录 | 作用 |
|---|---|
| [0.1版本需求](0.1版本需求/) | 当前 1.5 周调试演示版本需求 |
| [后续版本需求](后续版本需求/) | 0.1 之后逐步建设的完整系统需求 |

## 当前开发范围

当前优先按 `0.1版本需求` 执行。

0.1 版本只做：

- 焊丝存放完整流程。
- OP 存废焊丝并领取新焊丝主流程。
- 最小应用数据库库存记录。
- 最小格口控制。
- 手动控车。
- 必要 MES 查询和可标识的 Mock。

## 后续版本范围

以下需求不进入 0.1，统一放入 `后续版本需求`：

- 完整任务管理层。
- MES 自动派单。
- 完整 RCS 协同。
- 站点作业层。
- 流程模板层。
- 多点配送和多点收料。
- 自动回充。
- 完整权限、日志、审计。
- 全量异常处理。

## 原始文档说明

根目录下原有的大文档继续保留，作为详细资料来源。

开发和验收时，优先以版本目录为准；当版本目录没有覆盖到具体细节时，再参考原始大文档。
