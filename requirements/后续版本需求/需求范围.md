# 后续版本需求范围

## 1. 后续版本定位

后续版本用于在 0.1 调试版本基础上，逐步建设完整复合机器人发货柜系统。

0.1 版本只负责“焊丝流程 + 手动控车”。

后续版本负责：

- 自动任务。
- 完整调度。
- 完整站点作业。
- 完整 MES/RCS 协同。
- 流程模板配置。
- 生产级追溯和异常处理。

## 2. 建议版本拆分

### 2.1 0.2 版本：从手动控车到半自动任务

目标：在 0.1 基础上增加轻量任务概念，但不立刻做完整任务平台。

建议包含：

- 人工创建简单任务。
- 任务包含起点、终点、物料、目标格口。
- 手动选择任务后自动带出目标站点。
- 调用 RCS 移动到目标站点。
- 到站后进入对应 OP/MH 流程。
- 任务状态只保留：待执行、移动中、到站待作业、作业中、完成、失败。

暂不包含：

- MES 自动派单。
- 多任务排队。
- 多点配送。
- 自动回充。
- 复杂优先级。

### 2.2 0.3 版本：MES 自动派单和回传

目标：让系统可以从 MES 获取任务，并在完成后回传结果。

建议包含：

- MES 任务轮询或接收。
- MES 任务字段解析。
- MES 任务转换为内部任务。
- 重复任务识别。
- 任务接收结果回传。
- 作业完成回传。
- 关键异常回传。
- OP、站点、格口、物料、时间等追溯字段回传。

需要补充确认：

- MES 任务获取方式。
- MES 任务字段。
- 完成回传字段。
- 异常回传字段。
- OP 信息回传字段。

### 2.3 0.4 版本：完整机器人任务 / RCS 协同

目标：从“手动控车”升级为“任务驱动移动”。

建议包含：

- 机器人基础数据。
- RCS 站点映射。
- 机器人移动任务。
- RCS 下发目标站点。
- RCS 到站反馈。
- RCS 状态轮询。
- 到站超时处理。
- 移动失败处理。
- 移动前安全联锁。
- 任务完成后返回驻点。

后续再考虑：

- 低电量回充。
- 充电完成恢复任务。
- 任务取消和改派。
- 多点移动。

### 2.4 0.5 版本：完整站点作业层

目标：把到站后的人工操作从流程代码中抽象出来。

建议包含：

- 站点基础数据。
- 站点作业会话。
- 装货作业。
- 取货作业。
- OP 身份认证。
- 扫码校验。
- 站点是否允许装货/取货判断。
- 开格口前业务授权。
- 作业完成确认。
- 作业异常处理。

### 2.5 0.6 版本：流程模板层

目标：支持不同物料、不同任务类型使用不同规则。

建议包含：

- 流程模板基础配置。
- 是否需要扫码。
- 是否需要 OP 认证。
- 是否需要 MES 校验。
- 是否需要传感器确认。
- 是否允许人工确认。
- 是否允许混批。
- 是否允许代取。
- 是否允许人工放行。
- 模板版本管理。
- 模板快照。

注意：不建议一开始做完全自由编排流程引擎，先做有限配置项。

### 2.6 0.7 版本：全量硬件和生产级稳定性

目标：从演示格口扩展到完整发货柜。

建议包含：

- 全部格口 IO 映射。
- 多块 IO 模块。
- 批量读取锁状态。
- 批量读取传感器状态。
- 通信断开识别。
- 开锁超时识别。
- 状态不一致处理。
- 格口异常锁定。
- 格口禁用/启用。
- 全柜 HMI 展示。

### 2.7 1.0 版本：生产运行版

目标：满足生产试运行和验收。

建议包含：

- 完整任务闭环。
- MES 自动任务。
- RCS 自动移动。
- 完整站点作业。
- 完整流程模板。
- 完整权限。
- 完整日志追溯。
- 完整异常处理。
- 完整验收用例。

## 3. 后续版本功能清单

后续版本需要建设：

- MES 任务。
- 人工任务。
- 统一内部任务模型。
- 任务明细。
- 任务状态机。
- 任务来源。
- 任务优先级。
- 任务创建、开始、暂停、失败、完成、关闭。
- 任务与移动任务的关联。
- 任务与站点作业会话的关联。
- 任务追溯。

### 3.2 完整 MES 接口层

后续版本需要建设：

- MES 任务获取。
- MES 任务解析。
- 装货前 MES 校验。
- 取货前 MES 校验。
- 完成回传。
- 异常回传。
- OP 信息回传。
- 接口重试。
- 接口日志。
- MES 不通时的异常处理。

### 3.3 完整 RCS 协同

后续版本需要建设：

- RCS 站点映射。
- RCS 移动任务编号。
- RCS 下发。
- RCS 到站反馈。
- RCS 状态查询。
- RCS 失败码处理。
- 到站超时。
- 站点不一致处理。
- 急停、故障、手动模式处理。
- 低电量和回充。

### 3.4 完整站点作业层

后续版本需要建设：

- 到站后的装货/取货会话。
- 任务与站点匹配。
- OP 权限校验。
- 扫码校验。
- MES 校验结果处理。
- 开格口前授权。
- 人工确认。
- 人工放行。
- 作业完成和异常关闭。

### 3.5 流程模板层

后续版本需要建设：

- 物料类型匹配。
- 任务类型匹配。
- 模板启停。

- 模板快照。
- 不同物料的存取规则差异。

### 3.6 基础数据层

后续版本需要建设：

- 发货柜。

- 权限角色。

后续版本需要建设：

- 班组长/主管。
- OP。
- 维护人员。
- 接口用户。
- 强制开锁权限。
- 人工放行权限。

- 操作审计。

### 3.8 日志与追溯

后续版本需要建设：

- 任务日志。
- MES 接口日志。
- RCS 接口日志。
- 开锁日志。
- 扫码日志。
- OP 认证日志。
- 异常日志。
- 配置变更日志。
- 查询和导出。

## 4. 从 0.1 延后到后续的内容

以下内容明确不进入 0.1：

- 自动从 MES 获取任务。
- 根据 MES 任务自动派车。
- 完整任务生命周期管理。
- 多站点自动配送。
- 多点收料。
- 任务取消、改派、暂停、恢复。
- 低电量回充策略。
- 任务完成后自动回驻点。
- 复杂库存管理。
- 全量格口硬件接入。
- 完整物体检测。
- 完整门状态检测。
- 完整权限体系。
- 完整异常回传。
- 完整审计报表。

## 5. 后续版本待确认事项

后续版本启动前，需要优先确认：

- MES 任务获取方式。
- MES 任务字段。
- MES 完成回传字段。
- MES 异常回传字段。
- RCS 下发接口。
- RCS 到站反馈方式。
- RCS 状态字段。
- 全柜 IO 点位表。
- 每个格口是否有锁反馈、门反馈、物体检测。
- 现场站点编码。
- 低电量策略。
- 权限矩阵。
- 人工放行规则。
