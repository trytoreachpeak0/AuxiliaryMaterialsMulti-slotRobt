# 后续版本需求

## 目录定位

本目录用于存放 0.1 版本之后再建设的需求。

0.1 版本先完成：

- 焊丝存放完整流程。
- OP 存废取新主流程。
- 最小格口控制。
- 手动控车。

后续版本再逐步补齐完整平台能力。

## 后续版本总体方向

后续版本目标是从“调试演示闭环”升级为“可生产运行的复合机器人发货柜系统”。

重点包括：

- 完整任务管理层。
- MES 自动派单和结果回传。
- 完整机器人任务 / RCS 协同层。
- 站点作业层。
- 流程模板层。
- 完整基础数据和权限。
- 全格口硬件接入。
- 完整日志、审计和异常处理。
