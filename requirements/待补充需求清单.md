# 待补充需求清单

## 1. 文档说明

本文档用于汇总复合机器人发货柜系统后续仍需现场、MES、RCS、硬件、电气、工艺和管理方进一步确认的需求内容。

本清单不替代各层级需求文档。各项内容确认后，应同步补充到对应需求文档、接口说明、硬件点位表、流程模板或测试验收文档中。

## 2. MES 接口待补充需求

### 2.1 任务获取方式

需要确认：

- MES 任务由 MES 主动推送，还是由本系统定时拉取。
- 是否支持人工触发任务同步。
- MES 任务是否存在取消、变更、暂停或重派。
- 重复任务如何识别和处理。
- MES 任务获取失败后是否自动重试。

### 2.2 MES 任务字段

需要确认 MES 下发任务中包含哪些字段。

重点字段包括：

- MES 任务编号。
- 工单号。
- 物料编码。
- 物料名称。
- 物料类型。
- 批次号。
- 数量。
- 单位。
- 起始站点。
- 目标站点。
- 指定 OP 或班组。
- 要求完成时间。
- 优先级。
- 扩展字段。

### 2.3 装货前校验接口

需要确认：

- 装货前是否必须调用 MES 校验。
- 装货前校验请求字段。
- MES 校验通过、拒绝、超时、异常时分别如何处理。
- MES 校验拒绝时是否允许主管或管理员人工放行。
- 人工放行后是否仍需向 MES 回传。

### 2.4 取货前校验接口

需要确认：

- 取货前是否必须调用 MES 校验。
- 取货前校验是否校验 OP、工单、物料、批次、站点和格口。
- 指定 OP 取货、班组取货、代取分别如何校验。
- MES 校验失败时是否允许代取或人工放行。

### 2.5 完成回传字段

需要确认任务完成或任务明细完成后向 MES 回传哪些字段。

重点字段包括：

- MES 任务编号。
- 系统任务编号。
- 任务明细编号。
- 完成状态。
- 完成数量。
- 物料编码。
- 批次号。
- 工单号。
- 站点编号。
- 格口编号。
- OP 编号。
- OP 名称。
- 操作时间。
- 扫码内容。
- 异常标记。

### 2.6 异常回传字段

需要确认哪些异常必须回传 MES。

待确认异常包括：

- MES 校验失败。
- OP 无权限。
- 扫码失败。
- 物料不匹配。
- 格口开锁失败。
- 传感器异常。
- RCS 到站超时。
- 低电量中断。
- 人工放行。
- 任务人工关闭。

### 2.7 OP 信息回传要求

需要重点确认 OP 信息回传字段。

待确认字段包括：

- OP 编号。
- OP 名称。
- OP 工号。
- 班组。
- 部门。
- 角色。
- 操作类型。
- 操作站点。
- 操作格口。
- 操作时间。
- 是否代操作。
- 授权人。
- 认证方式。

## 3. RCS 接口待补充需求

### 3.1 目标站点下发

需要确认：

- RCS 目标站点下发接口形式。
- RCS 任务编号由谁生成。
- RCS 是否支持任务优先级。
- RCS 是否支持任务取消和改派。
- RCS 下发失败时返回哪些错误码。

### 3.2 到站反馈

需要确认：

- 到站反馈由 RCS 主动推送，还是本系统轮询查询。
- 到站反馈字段。
- RCS 返回的站点编码与系统站点编码如何映射。
- 到站超时时间如何配置。
- 到站站点不一致时如何处理。

### 3.3 机器人状态

需要确认 RCS 可提供哪些机器人状态。

待确认状态包括：

- 空闲。
- 移动中。
- 到站。
- 故障。
- 急停。
- 手动模式。
- 充电中。
- 电量。
- 当前站点。
- 当前 RCS 任务。

### 3.4 低电量与回充

需要确认：

- 电量数据来自 RCS、AGV 本体还是其他接口。
- 低电量阈值。
- 禁止接单阈值。
- 回充完成阈值。
- 低电量时当前任务是否继续执行。
- 充电完成后返回驻点还是继续任务。

## 4. 格口硬件待补充需求

### 4.1 锁控板信息

需要确认：

- 锁控板型号。
- 锁控板数量。
- 每块锁控板控制哪些格口。
- 通信协议。
- 通信地址。
- 是否支持心跳。
- 是否支持批量读取。

### 4.2 IO 点位表

需要补充完整 IO 点位表。

每个格口至少需要确认：

- 格口编号。
- 开锁输出点位。
- 锁状态输入点位，如果有。
- 门状态输入点位，如果有。
- 物体检测输入点位，如果有。
- 所属锁控板。
- 信号有效值。

### 4.3 电子锁反馈能力

需要确认：

- 电子锁是否有锁状态反馈。
- 是否能判断已锁和已释放。
- 是否能判断开锁失败。
- 开锁脉冲时长。
- 开锁后反馈超时时间。
- 是否支持重复开锁保护。

### 4.4 门状态检测能力

需要确认：

- 当前格口是否有独立门状态检测。
- 是否能判断门打开。
- 是否能判断门关闭。
- AGV 移动前是否必须确认门关闭。
- 没有门状态检测时使用什么信号替代安全联锁。

### 4.5 物体检测传感器

需要确认：

- 哪些格口配置物体检测传感器。
- 传感器类型。
- 是否能稳定检测实际物料。
- 装货后是否强制要求检测到有物。
- 取货后是否强制要求检测到无物。
- 传感器异常时是否允许人工确认。

## 5. 业务规则待补充需求

### 5.1 物料规则

需要确认：

- 哪些物料属于普通辅料。
- 哪些物料属于受控物料。
- 哪些物料必须扫码。
- 哪些物料必须 MES 强校验。
- 哪些物料必须绑定 OP。
- 哪些物料允许人工放行。
- 是否允许同格口多物料。
- 是否允许混批。

### 5.2 OP 绑定规则

需要确认：

- 装货 OP 是否需要绑定。
- 取货 OP 是否需要绑定。
- 是否允许同班组代取。
- 是否允许主管代取。
- 代取是否需要 MES 校验。
- 代取是否需要回传原指定 OP 和实际取货 OP。

### 5.3 人工放行规则

需要确认：

- 哪些异常允许人工放行。
- 哪些角色可以人工放行。
- 人工放行是否需要输入原因。
- 人工放行是否需要二次确认。
- 人工放行后是否继续回传 MES。
- 人工放行是否影响任务完成状态。

### 5.4 驻点发料规则

需要确认：

- 驻点发料时机器人停留在哪些站点。
- 是否支持多个 OP 在同一驻点领取不同物料。
- OP 领取前是否必须有 MES 任务。
- 是否允许无任务领料。
- 是否支持补料呼叫。
- 驻点发料任务如何结束。

### 5.5 多点配送与多点收料规则

需要确认：

- 多点配送的站点顺序由谁决定。
- 某个站点作业失败后是否继续下一个站点。
- 多点收料是否允许中途回充。
- 已完成和未完成明细如何拆分追溯。
- 任务中断后如何恢复。

## 6. 权限待补充需求

### 6.1 角色定义

需要确认现场角色清单。

建议至少包括：

- OP 操作员。
- 主管或班组长。
- 管理员。
- 维护人员。
- 系统接口用户。

### 6.2 权限矩阵

需要补充每个角色可执行的操作。

重点权限包括：

- 查看任务。
- 执行装货。
- 执行取货。
- 扫码确认。
- 创建人工任务。
- 发起补料呼叫。
- 主管放行。
- 任务异常关闭。
- 修改基础数据。
- 修改流程模板。
- 修改 IO 映射。
- 查看日志。
- 导出日志。

### 6.3 高风险操作

需要确认哪些操作属于高风险操作。

建议高风险操作包括：

- 人工放行。
- 强制完成任务。
- 强制关闭任务。
- 禁用或启用格口。
- 修改 RCS 站点映射。
- 修改 MES 编码映射。
- 修改格口 IO 映射。
- 修改角色权限。

## 7. 异常处理待补充需求

### 7.1 业务异常

需要确认以下异常如何处理：

- OP 无权限。
- 扫码错误。
- 物料不匹配。
- 批次不匹配。
- 工单不匹配。
- 当前站点不匹配。
- 任务已取消或已完成。

### 7.2 硬件异常

需要确认以下异常如何处理：

- 锁控板通信异常。
- 开锁失败。
- 锁状态不一致。
- 门状态异常。
- 传感器异常。
- 格口无法确认关闭。

### 7.3 MES 异常

需要确认以下异常如何处理：

- MES 不通。
- MES 校验超时。
- MES 校验拒绝。
- MES 回传失败。
- MES 返回任务状态与本系统不一致。

### 7.4 RCS 异常

需要确认以下异常如何处理：

- RCS 不通。
- 目标站点下发失败。
- AGV 到站超时。
- AGV 位置不一致。
- AGV 故障。
- AGV 急停。
- 低电量中断。

## 8. 日志与追溯待补充需求

### 8.1 日志保留周期

需要确认：

- 任务日志保留多久。
- MES 接口日志保留多久。
- RCS 接口日志保留多久。
- 开锁日志保留多久。
- 扫码日志保留多久。
- 人工放行日志保留多久。
- 配置变更日志保留多久。

### 8.2 日志查询与导出

需要确认：

- 哪些角色可以查看日志。
- 哪些角色可以导出日志。
- 导出格式。
- 是否需要脱敏。
- 是否需要按任务、物料、格口、OP、时间范围查询。

### 8.3 审计要求

需要确认：

- 是否需要满足客户审计要求。
- 是否需要防篡改。
- 是否需要记录完整接口报文。
- 是否需要记录配置变更前后差异。
- 是否需要支持异常复盘报告。

## 9. 验收待补充需求

### 9.1 功能验收

需要补充各业务模式的验收场景。

建议包括：

- 驻点发料完整流程。
- 多点配送完整流程。
- 多点收料完整流程。
- MES 强校验流程。
- 人工放行流程。
- 低电量回充流程。
- 充电完成返回驻点流程。

### 9.2 异常验收

需要补充异常验收场景。

建议包括：

- MES 不通。
- RCS 不通。
- 锁控板不通。
- 开锁失败。
- 传感器异常。
- AGV 到站超时。
- OP 无权限。
- 扫码错误。
- 格口未关闭禁止移动。

### 9.3 数据验收

需要补充数据验收内容。

建议包括：

- 任务状态完整。
- OP 信息回传完整。
- MES 回传成功。
- 日志可追溯。
- 配置变更可审计。
- 历史任务不受新配置影响。
