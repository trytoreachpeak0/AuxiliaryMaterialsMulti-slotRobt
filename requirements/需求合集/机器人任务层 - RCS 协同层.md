# 机器人任务层 / RCS 协同层 Robot Task / RCS Collaboration Layer

## 1. 文档说明

### 1.1 文档目的

机器人任务层 / RCS 协同层负责将业务任务中的移动需求转换为 RCS 可执行的 AGV 调度任务，并接收 AGV 到站、移动中、失败、取消、低电量、充电完成等反馈。

本层应支持 AGV 目标站点下发、到站反馈、移动前安全联锁确认、低电量回充、充电完成后返回驻点或继续任务，以及 RCS 通信异常时的任务保护。

本文档用于说明机器人任务层 / RCS 协同层在需求阶段需要具备的对象定义、状态定义、控制能力、异常处理和日志追溯要求，不描述具体 RCS 厂商协议、接口报文格式或调度算法实现。

### 1.2 职责边界

机器人任务层 / RCS 协同层负责“机器人去哪里、是否到站、是否允许移动”。

简单来说：

- 任务管理层负责“业务任务当前执行到哪一步”。
- 机器人任务层负责“根据任务要求调用 RCS，让 AGV 到达指定站点”。
- RCS 负责“路径规划、交通管制、AGV 实际运动控制和到站反馈”。
- 站点作业层负责“AGV 到站后 OP 怎么装货、取货和确认”。
- 格口控制层和格口硬件控制层负责“格口是否关闭、锁是否正常、传感器是否正常”等安全联锁依据。

机器人任务层不直接控制底盘电机，不直接规划路径，不直接开格口，也不替代站点作业层完成 OP 作业确认。

### 1.3 一期建设原则

一期应优先支持单车单柜、固定站点、固定充电站和有限业务模式下的稳定移动闭环。

一期至少应支持：

- 下发 AGV 去目标站点。
- 查询 AGV 当前状态和当前位置。
- 接收到站反馈后通知任务管理层和站点作业层。
- 移动前检查格口、柜门、锁控、通信和任务状态是否允许移动。
- 低电量时中断或延后新任务，并调度 AGV 回充。
- 充电完成后返回驻点或按任务策略继续执行。
- RCS 通信异常、移动失败、到站超时和人工急停后的异常处理。

## 2. 控制对象

### 2.1 复合机器人 Robot

复合机器人是承载发货柜并由 RCS 调度移动的设备。

复合机器人至少包含：

- 机器人编号。
- 机器人名称。
- RCS 设备编码。
- 关联发货柜编号。
- 当前站点。
- 当前 RCS 状态。
- 当前业务状态。
- 当前电量。
- 当前任务编号，如果有。
- 通信状态。
- 启用/禁用状态。

当前阶段，一个复合机器人默认挂载一个发货柜。若后续支持一车多柜或换柜，应在基础数据层扩展机器人与发货柜的绑定关系。

### 2.2 RCS 站点 RCS Station

RCS 站点是 RCS 系统中可供 AGV 到达、等待、充电或作业的位置。

系统内站点应维护业务站点编号与 RCS 站点编码的映射关系。

站点至少包含：

- 系统站点编号。
- RCS 站点编码。
- 站点名称。
- 站点类型，例如装货站、取货站、驻点、充电站、异常处理站。
- 是否允许停靠。
- 是否允许作业。
- 是否允许作为低电量回充目标。
- 启用/禁用状态。

机器人任务层下发移动任务时，应使用 RCS 可识别的站点编码。

### 2.3 机器人移动任务 Robot Move Task

机器人移动任务表示一次从当前位置移动到目标站点的 RCS 调度请求。

机器人移动任务至少包含：

- 移动任务编号。
- 关联业务任务编号。
- 关联机器人编号。
- 起始站点。
- 目标站点。
- RCS 任务编号。
- 移动任务状态。
- 优先级。
- 下发时间。
- 到站时间。
- 失败原因，如果有。

一个业务任务可能包含多个移动任务。例如多点配送任务中，AGV 可能依次前往装货站、多个取货站或卸货站、驻点或充电站。

### 2.4 驻点 Home Station

驻点是机器人空闲、等待任务或充电完成后默认返回的位置。

系统应支持为每台复合机器人配置默认驻点，也可按业务模式配置任务完成后的返回站点。

驻点至少需要明确：

- 驻点站点编号。
- 适用机器人。
- 是否允许长期停靠。
- 是否允许驻点发料。
- 是否允许任务完成后自动返回。

### 2.5 充电站 Charge Station

充电站是机器人低电量或任务结束后执行充电的目标站点。

充电站至少需要明确：

- 充电站编号。
- RCS 站点编码。
- 适用机器人或适用区域。
- 是否启用。
- 是否允许自动回充。
- 充电完成后的返回策略。

## 3. 状态定义

### 3.1 机器人业务状态

机器人业务状态用于描述机器人在本系统中的业务可用性。

建议状态包括：

- 空闲。
- 执行任务中。
- 移动中。
- 到站待作业。
- 作业中。
- 回充中。
- 充电中。
- 充电完成待返回。
- 异常。
- 禁用。

业务状态应由本系统根据任务、RCS 反馈、站点作业状态和异常状态综合维护，不应直接等同于 RCS 原始状态。

### 3.2 RCS 通信状态

RCS 通信状态用于判断系统是否可与 RCS 正常交互。

建议状态包括：

- 未连接。
- 已连接。
- 请求超时。
- 心跳异常。
- 返回异常。
- 协议异常。

当 RCS 通信异常时，系统不得继续下发新的移动任务；已下发任务应进入待确认或异常保护状态，并提示人工确认机器人实际位置。

### 3.3 移动任务状态

移动任务状态用于追踪单次移动请求的执行过程。

建议状态包括：

- 待下发。
- 下发中。
- 已下发。
- 移动中。
- 已到站。
- 已取消。
- 下发失败。
- 移动失败。
- 到站超时。
- 异常关闭。

移动任务状态变化应同步影响关联业务任务的执行阶段，但不应直接把业务任务置为完成。

### 3.4 电量状态

电量状态用于判断机器人是否允许继续接收任务或需要回充。

建议状态包括：

- 电量正常。
- 电量偏低。
- 低电量需回充。
- 极低电量禁止执行任务。
- 充电中。
- 充电完成。

低电量阈值、禁止接单阈值、回充完成阈值应作为可配置参数维护。

## 4. 控制能力需求

### 4.1 目标站点下发能力

机器人任务层应支持根据业务任务和流程模板生成目标站点，并向 RCS 下发移动请求。

下发前至少应校验：

- 机器人启用且在线。
- 机器人未处于不可打断作业状态。
- 目标站点启用且存在 RCS 站点编码。
- 当前业务任务处于允许移动的状态。
- 格口、电子锁、柜门或传感器状态满足移动安全要求。
- 机器人电量满足本次移动要求。
- RCS 通信正常。

若任一校验失败，不得下发移动任务，并应返回明确失败原因。

### 4.2 到站反馈处理能力

机器人任务层应接收 RCS 到站反馈或主动查询到站状态。

到站后系统应：

- 更新机器人当前站点。
- 更新移动任务为已到站。
- 通知任务管理层进入对应任务阶段。
- 通知站点作业层创建或恢复站点作业会话。
- 记录到站时间、目标站点和 RCS 返回信息。

若 RCS 反馈站点与业务目标站点不一致，应进入异常状态，普通 OP 不得执行开格口或作业完成确认。

### 4.3 移动前安全联锁确认

移动前必须执行安全联锁确认。

安全联锁至少包括：

- 所有要求关闭的格口已关闭或锁状态正常。
- 不存在正在执行的开锁指令。
- 不存在未处理的格口硬件异常。
- 发货柜控制器通信正常。
- RCS 通信正常。
- 机器人未处于急停、故障、手动模式等不可移动状态。
- 当前站点作业已完成或已被授权放行。

安全联锁失败时，系统不得下发移动任务，并应向界面层返回可理解的原因，例如“格口 A01 未关闭”或“锁控板通信异常”。

### 4.4 低电量回充能力

系统应根据电量阈值判断是否触发低电量回充。

低电量处理原则：

- 空闲机器人低电量时，应自动下发回充任务。
- 任务执行中低电量时，应按任务策略判断是否继续当前站点、先完成当前作业或立即回充。
- 极低电量时，应禁止接收新任务，并优先回充或提示人工处理。
- 回充前仍应执行移动前安全联锁确认。

低电量回充不得丢失当前业务任务信息。未完成任务应进入暂停、等待回充完成或人工处理状态。

### 4.5 充电完成返回驻点能力

充电完成后，系统应根据配置决定机器人下一步动作。

建议策略包括：

- 返回默认驻点。
- 返回任务暂停前站点。
- 继续执行未完成任务。
- 保持在充电站等待人工确认。

若充电完成后需要返回驻点或继续任务，应重新执行移动前安全联锁确认和 RCS 通信确认。

### 4.6 任务取消与改派能力

系统应支持在业务允许的情况下取消尚未完成的移动任务。

取消前应判断：

- RCS 是否支持取消当前任务。
- 机器人是否已经到站。
- 是否存在站点作业正在进行。
- 取消后业务任务应进入什么状态。

任务取消、改派或人工接管都必须记录原因和操作人。

## 5. 异常处理

### 5.1 RCS 下发失败

RCS 下发失败时，移动任务应记录失败原因，并返回任务管理层。

系统应支持人工重试、改派目标站点、关闭移动任务或转人工处理。

### 5.2 到站超时

移动任务下发后，若超过配置时间仍未收到到站反馈，应标记为到站超时。

到站超时后应：

- 查询 RCS 当前任务状态。
- 查询机器人当前位置。
- 提示人工确认。
- 禁止直接进入站点作业。

### 5.3 低电量中断

任务执行中触发低电量回充时，应记录中断点。

中断点至少包括：

- 当前业务任务编号。
- 当前执行阶段。
- 当前站点。
- 已完成和未完成任务明细。
- 当前格口状态。

### 5.4 位置不一致

若系统记录站点、RCS 返回站点和人工确认位置不一致，应进入位置异常。

位置异常解除前，不得允许普通业务开格口、完成任务或下发下一段移动。

## 6. 日志与追溯

机器人任务层 / RCS 协同层应记录：

- 移动任务创建、下发、到站、取消、失败和关闭日志。
- RCS 请求和响应摘要。
- 机器人当前位置变化。
- 电量状态变化。
- 低电量回充触发原因。
- 充电开始、充电完成和返回驻点记录。
- 移动前安全联锁检查结果。
- 人工重试、取消、改派和异常放行记录。

日志应至少关联业务任务编号、机器人编号、发货柜编号、目标站点、操作人、操作时间和结果。
