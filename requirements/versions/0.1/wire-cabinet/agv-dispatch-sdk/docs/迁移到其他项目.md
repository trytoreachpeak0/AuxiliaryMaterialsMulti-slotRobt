# 把 AGV SDK 迁到另一个文件夹 / 项目

当前仓库里和 **封装** 相关的有多块，不必整仓拷贝。

## 目录对照（你只要关心这几块）

| 文件夹 | 要不要拷 | 说明 |
|--------|----------|------|
| **`AgvDispatch.Sdk/`** | **必拷** | 类库本体，你的新项目只引用它即可 |
| **`docs/`** | 建议拷 | 使用说明、场景、LLM 指南、fixtures、schema |
| **`AgvDispatch.Sample/`** | 可选 | 示例与 `Integration/AgvControlLoop.cs`，集成时可复制其中文件 |
| `AgvDispatch.Sdk.Tests/` | 可选 | 单元测试，新项目不需要可不带 |
| `AgvDispatch.sln` | 可选 | 仅在本仓库多项目编译用 |
| **`StandAGVClient/`** | **不要拷** | 旧 net48 物料间客户端，与 SDK 无关 |
| `packages/` | **不要拷** | 旧 WinForms 的 NuGet，SDK 不用 |
| `bin/`、`obj/` | **不要拷** | 编译产物，到新目录 `dotnet build` 会重新生成 |

根目录还有 **`AGENTS.md`**、**`llms.txt`**（给 AI 读文档用），需要可一并拷到目标仓库根目录。

---

## 方式一：只拷「源码包」（推荐）

在资源管理器中复制下面 **3 项** 到你的新解决方案目录，例如 `D:\MyApp\libs\AgvDispatch\`：

```
AgvDispatch.Sdk\          （整个文件夹，但不要里面的 bin、obj）
docs\
AGENTS.md                 （可选）
```

或在仓库根目录 PowerShell 执行（自动生成干净导出目录）：

```powershell
.\scripts\Export-AgvDispatch.ps1 -OutputDir "D:\你的路径\AgvDispatch-Export"
```

再把 `AgvDispatch-Export` 整个拷走即可。

---

## 方式二：在新项目里用「项目引用」（最省事）

新 .NET 8 项目 **不必移动 SDK 源码**，只要 `.csproj` 指过来：

```xml
<ItemGroup>
  <ProjectReference Include="..\..\libs\AgvDispatch.Sdk\AgvDispatch.Sdk.csproj" />
</ItemGroup>
```

路径按你实际放置 `AgvDispatch.Sdk` 的位置改。  
SDK 留在磁盘一处，多个项目可共用同一份源码。

---

## 方式三：打成 NuGet（团队分发）

在 `AgvDispatch.Sdk` 目录：

```powershell
dotnet pack -c Release -o .\nupkg
```

把生成的 `AgvDispatch.Sdk.1.0.0.nupkg` 拷到目标机器，新项目：

```xml
<PackageReference Include="AgvDispatch.Sdk" Version="1.0.0" />
```

（需配置本地 feed 或推到内部 NuGet 服务器。）

---

## 方式四：只拷 DLL（不推荐长期用）

```powershell
dotnet build AgvDispatch.Sdk\AgvDispatch.Sdk.csproj -c Release
```

复制 `AgvDispatch.Sdk\bin\Release\net8.0\AgvDispatch.Sdk.dll` 到目标项目并「添加引用」。  
**缺点**：没有 IntelliSense/XML 文档，改配置也不方便，只适合临时试用。

---

## 新项目最少步骤

1. 目标解决方案为 **net8.0**。
2. 按方式一或二放入 `AgvDispatch.Sdk`。
3. 引用 + 注册：

```csharp
services.AddAgvDispatchClient(o =>
    configuration.GetSection(AgvDispatchOptions.SectionName).Bind(o));
```

4. 从 `AgvDispatch.Sample/Integration/AgvControlLoop.cs` 复制主循环（或参考 `Scenarios`）。
5. 复制 `AgvDispatch.Sdk/appsettings.example.json` 到你的 `appsettings.json` 并改配置。

---

## 若还想带示例一起迁

额外复制 **`AgvDispatch.Sample/`**（同样不要 bin/obj），在新目录：

```powershell
dotnet build AgvDispatch.sln
dotnet run --project AgvDispatch.Sample -- poll
```

也可把 Sample 里的 `Integration`、`Scenarios`、`SampleRuntime.cs` 剪贴到你的业务工程，不必整个 Sample 项目都进解决方案。
