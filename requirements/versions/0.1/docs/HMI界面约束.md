# 0.1 HMI 界面约束（一体机）

> 正式约束本文；布局与控件样式原型见 [`WireDispenser.Demo`](../../../../WireDispenser.Demo/)（**UI 参考，非 0.1 交付宿主**）。Demo 接入说明见 [`界面接入业务与交互逻辑说明.md`](../../../../WireDispenser.Demo/界面接入业务与交互逻辑说明.md)。

## 1. 目标设备

工业一体机：**1024×768（4:3）**、约 12.1 英寸、电容触控。焊丝柜触控屏 HMI 均须遵守本节。

## 2. 窗口与布局

| 约束 | 要求 |
|------|------|
| 窗口尺寸 | 固定 `1024×768`，`ResizeMode=NoResize`（现场全屏/无边框由宿主配置，但逻辑分辨率按 4:3 设计） |
| 禁止滚动 | 不得用 `ScrollViewer` 让主流程页滚动；信息须一屏内可见 |
| 大网格例外 | MH 格口状态网格可用 `Viewbox` 等比缩放，**不是**纵向滚动 |
| 角色壳 | 顶栏 **操作员 OP / 物料员 MH** 切换；底部 **状态栏**（当前步骤/校验/错误，中文） |

## 3. 字号与触控

| 项 | 下限 | 参考 |
|----|------|------|
| 正文/标签 | ≥ 14px | Demo `LabelText`（15） |
| 关键值/输入 | ≥ 17px | Demo `ValueText`（17）、`IndustrialTextBox` |
| 区块标题 | ≥ 18px | Demo `SectionTitle` |
| 输入框高度 | ≥ 42px | Demo `IndustrialTextBox` |
| 主按钮高度 | 44～46px | Demo `PrimaryButton` |

## 4. 视觉风格

- 工厂风：对比清晰、无花哨动画/渐变。
- 配色与控件样式**统一走主题资源**（Demo 为 `Styles/IndustrialTheme.xaml` 中的画刷/样式键）；新页面勿随意硬编码颜色。
- 语义色：成功/警告/危险/强调与格口状态色与主题一致。

## 5. 分步交互（业务页）

OP、MH 存料页须实现分步点亮、锁定、级联清空（详见 [OP界面-分步交互规范](OP界面-分步交互规范.md)、[MH界面-分步交互规范](MH界面-分步交互规范.md)）。
