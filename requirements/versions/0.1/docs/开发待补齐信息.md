## 7. 建议开工顺序

```text
1. 读 需求范围 + docs/格口硬件 → 格口控制 → slot-config
2. 实现 D1/D2（可用单机 Modbus 模拟器先测 1 模块 1 格）
3. 导入 D4 + 接 lab 或正式 app.* SQL（D3/D5）
4. 接 flow 引擎 + 单流程（load_available_wire）
5. 接 agv-dispatch-sdk + P2–P5 现场配置
6. 端到端按 验收清单 脚本 1→5
```
