# 0.1 版本验收清单

## 1. 验收目标

- **定位**：3 天调试演示可用的 **80 分** 验收，不是完整一期系统。
- **核心**：6 条焊丝流程可操作、真实格口可证明、真实 MES/RCS 联调、手动控车闭环、低电量回充闭环、关键异常不卡死。
- **原则**：**全部真实联调**，不提供 Mock；不得按「全平台 / 全格口出厂验收」标准卡 0.1。

---

## 2. 80 分模块标准

| 模块 | 80 分要求 | 演示要求 |
|------|-----------|----------|
| MH 存焊丝 | 批号→MES→空格口→开锁→确认→库与格口更新 | **必演** 脚本 1 |
| OP 存废取新 | OP/焊丝/机台校验→MES 用量与退料→退旧取新→库更新 | **必演** 脚本 2 |
| MH 开单格口 | 选一格真开锁并更新状态 | 脚本 5 |
| MH 批量开格口 | 三种 bulk flow 至少各成功 1 次（已启用格口） | 脚本 5 |
| MES | 查询 + 配额 + 退料 **全部真库成功路径** | 脚本 1、2 |
| 应用库 | 格口、焊丝、操作日志正确 | 脚本 1、2 |
| 格口硬件 | 见 §3；至少 **B 级** | 脚本 1、2、5 |
| 手动控车 | 真实 RCS：选站→下发→Arrived；未到站禁焊丝 | **必演** 脚本 3 |
| 低电量回充 | 真实低电量或现场约定触发→充电单→回驻点 | **必演** 脚本 4 |
| 安全联锁 | 开锁中/存取中禁移动；移动中门开暂停 | 脚本 3 + 抽查 |
| OP/MH 分步 UI | 分步点亮、通过后锁定、清空级联、重新开始；未到站禁操作 | 脚本 1、2 抽查 |
| 异常提示 | §6 列表均有中文提示且可恢复 | 抽查 |
| 演示材料 | 脚本、已知限制、联调环境说明 | 交付 §8 |

---

## 3. 格口验收分级（满足其一即可达 80 分格口项）

| 级别 | 标准 | 适用 |
|------|------|------|
| **A** | 全柜已启用格口 IO 映射完成；随机抽测 **≥5 格** 真开锁成功 | 30+ 格现场已接线 |
| **B** | 映射表覆盖全柜；**≥2 格** 真开锁 + 其余**已启用**格口界面状态正确 | 部分格未接线则标为禁用 |
| **C** | 仅 1～2 格真锁、无全柜映射 | **不达标** |

未接线格口须在配置中 **禁用**，不得用软件假锁冒充真开。

批量开格口：在 **B 级及以上** 前提下，对「所有可用 / 所有归还 / 所有」中至少一种完成端到端（含状态更新）。

## 5. 必须演示的 5 条脚本

### 脚本 1：MH 存可用焊丝

```text
（若需）真实 RCS 控车至作业站并 Arrived
→ MH 存焊丝：批号 → MES → 空格口 → 真开锁 → 确认放入
→ 格口「有新料」、柜内焊丝在柜、日志 OK
```

**分步 UI 检查**（见 [MH界面-分步交互规范](docs/MH界面-分步交互规范.md) §5）：批号步锁定、清空级联、「重新开始」、未到站禁开锁。

**通过**：焊丝信息可见；格口状态变化正确；日志含真实 MES/开锁结果。

---

### 脚本 2：OP 存废取新

```text
作业站已到站（真实 RCS）
→ OP：工号班组班次 → MES OP → 旧批号 → 规格 → 匹配新料 → 归还重量
→ 机台 → 产品批 → MES 用量核对（ORA-20007 可重输）→ MES 退料提交（v_Task=归还）
→ 回收格口真开 → 确认放入 → MES 领用提交（v_Task=领用）→ 新料格口真开 → 确认取出 → 库存/日志更新
```

**分步 UI 检查**（见 [OP界面-分步交互规范](docs/OP界面-分步交互规范.md) §5）：冷启动仅①可输入；通过后锁定；清空批号级联；「重新开始」有效；未到站不可开锁/提交。

**通过**：MES 写操作在日志中可追溯且为真实调用；双格口真开；新料已取出、旧料已回收（或约定态）。

---

### 脚本 3：手动控车与到站门禁

```text
当前不在目标作业站
→ 真实 RCS：选作业站 → 移动前检查 → 下发 → Moving → Arrived
→ 未 Arrived 或车在错误作业站 / 角色与站点不符 → 对应存取应禁止并提示
→ 车在 MH 站 + MH 角色可脚本 1；车在 OP 站 + OP 角色可脚本 2
```

**通过**：`currentPosition` 与目标一致；门禁有效；日志有真实订单 id。

---

### 脚本 4：低电量自动回充

```text
电量低于配置阈值（现场真实或运维临时下调阈值触发，须在演示脚本注明）
→ 自动下真实充电单 → 充电中禁开格口（可演示充电中手动离站/移站）
→ 达到充满阈值 → 自动返航 **充点前作业站** → Arrived 该作业站
→ 日志含回充与返航记录
```

**通过**：全程真实 RCS；充后回到充点前作业站（非第三类驻点）；无人工假造到站/充电成功。

---

### 脚本 5：MH 格口维护

```text
→ 单格：真开锁 → 关门确认 → 状态更新
→ 任选两种 bulk flow：真开锁 ≥1 格 → 日志
```

**通过**：单开 OK；流程矩阵至少 2 项 bulk 通过。

---

## 6. 必须覆盖的异常

每项须：**中文提示、不崩溃、可重试、日志有原因**。

| 类别 | 异常 |
|------|------|
| MES/业务 | OP 不存在；焊丝批号不存在；规格不存在；归还重量不存在；无同规格新料；机台不存在；产品批 N/A；用量失败（含 ORA-20007 重输）；退料失败；产品信息不存在；领用提交失败 |
| 格口 | 开锁失败；开锁超时；无可用回收格口 |
| 控车 | RCS 不通；下发失败；到站超时；充电桩占用 |
| 门禁 | 未到站操作焊丝；充电中操作焊丝 |
| 会话 | 已有焊丝会话时进入第二流程（须提示并拒绝） |

## 7. 验收前配置检查（现场冻结）

| 项 | 是否已填 | 存放 |
|----|----------|------|
| RCS BaseUrl、账号、DefaultDeviceKey | ☐ | appsettings |
| `wire-cabinet/station-config/stations.yaml`（多作业站 OP/MH 分工 + 单充电点 RCS 号） | ☐ | 由 template 复制填写 |
| 低电量%、充满%、到站超时 | ☐ | 阈值配置 |
| 格口 IO 映射、联锁格口数（enabled∧wired） | ☐ | 硬件配置；门联锁不用 closeFlag |
| `io-modules.yaml`（4 模块 IP，由 template 复制填写） | ☐ | wire-cabinet/slot-config/ |
| 批量开锁：间隔 300～500 ms（默认 400）、失败立刻中止 | ☑ 已冻结 | `SlotBatchOpen:IntervalMs` / `StopOnFailure=true` |
| MES 测试库（含配额、退料/领用写权限） | ☐ | 运维文档 |
| 演示批号 / OP / 机台数据有效 | ☐ | 运维文档 |
| ChargeDestination、ChargeActionId | ☐ | appsettings |

详见 [RCS协同层-0.1.md](docs/RCS协同层-0.1.md) §5、[agv-dispatch-sdk/AgvDispatch.Sdk/appsettings.example.json](agv-dispatch-sdk/AgvDispatch.Sdk/appsettings.example.json)。

## 9. 未通过条件（任一条即不达标）

- 脚本 1 或 2 主路径无法完成
- MES 配额或退料未真实调用却显示成功
- 脚本 3 非真实 RCS 或到站门禁无效
- 脚本 4 无法自动回充或无法回驻点
- 核心业务两条 flow 未实现
- 格口仅 C 级，或存在软件假锁冒充真开
- 格口状态与库存明显不一致
- 失败后界面卡死、无法继续
- 任一模块依赖 Mock/模拟模式完成演示
