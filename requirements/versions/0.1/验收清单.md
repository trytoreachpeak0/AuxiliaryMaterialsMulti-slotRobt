# 0.1 版本验收清单

## 1. 验收目标

0.1 版本以 80 分调试演示为目标，验收重点是主流程能跑通、关键接口能联调、硬件动作可证明。

不以完整一期系统为验收标准。

## 2. 80 分验收标准

| 模块 | 80 分要求 | 备注 |
|---|---|---|
| MH 存焊丝 | 能完成扫码/录入、查 MES、开格口、确认放入、写库存 | 必须演示成功路径 |
| OP 存废取新 | 能完成 OP 校验、旧焊丝校验、同规格匹配、退旧、取新 | 必须演示成功路径 |
| MES 查询 | 操作员、焊丝批号、机台、最近产品批次号至少能联调 | 优先真 MES 测试库 |
| MES 写操作 | 配额核对和退料提交可真实联调；未确认时可 Mock | Mock 必须在界面和日志标识 |
| 应用数据库 | 能记录格口状态、柜内焊丝、操作日志 | 不要求完整任务表 |
| 格口控制 | 至少 1 到 2 个格口可真实开锁或稳定模拟 | 真锁优先 |
| 手动控车 | 能手动选择站点并调用 RCS 或 Mock RCS 到站 | 不要求自动派单 |
| 安全限制 | 移动前检查正在开锁/正在操作状态 | 0.1 只做最小联锁 |
| 异常提示 | 常见失败有明确中文提示 | 不能无响应或卡死 |
| 演示材料 | 有演示脚本、已知限制和后续计划 | 防止按完整系统验收 |

## 3. 必须演示的 3 条脚本

### 3.1 脚本一：MH 存焊丝

```text
进入 MH 界面
→ 输入或扫码焊丝批号
→ 查询 MES 返回焊丝规格
→ 系统找到空格口
→ 打开格口
→ 确认放入
→ 应用数据库记录在柜焊丝
→ 格口状态显示有料
```

验收通过条件：

- 界面显示焊丝信息。
- 格口状态从空闲变为有料。
- 操作日志有记录。

### 3.2 脚本二：OP 存废取新

```text
进入 OP 界面
→ 输入 OP 工号、班组、班次
→ 查询 MES 校验 OP
→ 输入旧焊丝批号
→ 查询 MES 获取规格
→ 系统匹配柜内同规格新焊丝
→ 输入机台号
→ 查询 MES 校验机台
→ 查询最近产品批次
→ 配额核对或 Mock 配额核对
→ 退料提交或 Mock 退料提交
→ 打开回收格口
→ 确认放入旧焊丝
→ 打开新料格口
→ 确认取出新焊丝
→ 库存和日志更新
```

验收通过条件：

- OP、焊丝、机台校验结果可见。
- 回收格口和新料格口动作可见。
- 新料从在柜状态变为已取出。
- 旧料记录为已回收或回收待处理。

### 3.3 脚本三：手动控车

```text
进入手动控车界面
→ 选择目标站点
→ 系统检查当前是否允许移动
→ 调用 RCS 或 Mock RCS
→ 显示移动中
→ 显示已到站
→ 到站后允许执行焊丝流程
```

验收通过条件：

- 可以选择固定站点。
- 移动状态变化清楚。
- 到站后当前站点显示正确。
- 未到站时不允许执行需要到站的取放操作。

## 4. 必须覆盖的异常

0.1 至少覆盖：

- OP 不存在。
- 焊丝批号不存在。
- 柜内无同规格焊丝。
- 机台不存在。
- 格口开锁失败或超时。
- RCS 下发失败或到站超时。

每个异常都需要：

- 中文提示。
- 不崩溃。
- 可返回重新输入或重新操作。
- 操作日志记录失败原因。

## 5. Mock 允许范围

0.1 可以 Mock：

- RCS 下发和到站反馈。
- MES 配额核对。
- MES 退料提交。
- 门状态或物体检测。

0.1 不建议 Mock：

- OP 查询。
- 焊丝批号查询。
- 机台查询。
- 应用数据库库存状态。

如果必须 Mock，必须在界面和日志中显示，避免误认为已经真实联调完成。

## 6. 交付物

0.1 版本交付时至少包含：

- 可运行程序。
- 0.1 需求范围说明。
- 0.1 验收清单。
- 演示脚本。
- 已知限制列表。
- MES/RCS/格口 Mock 状态说明。
- `versions/final/` 最终版本需求目录。

## 7. 未通过条件

出现以下情况应判定 0.1 未达 80 分：

- MH 存焊丝主流程不能跑通。
- OP 存废取新主流程不能跑通。
- 格口状态不能正确更新。
- 没有任何真实或模拟格口开锁动作。
- 手动控车没有状态闭环。
- 失败后程序卡死或无法继续操作。
- Mock 项未标识，导致验收方误判真实联调状态。
