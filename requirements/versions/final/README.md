# Final Version Requirements

## 目录定位

本目录用于存放最终生产版本需求，描述从 0.1 调试演示闭环逐步补齐后的完整系统能力。

0.1 版本先完成：

- 焊丝存放完整流程。
- OP 存废取新主流程。
- 最小格口控制。
- 手动控车。

0.2 等中间版本可以从这里拆分增量范围，但最终以本目录和 `../../baseline/` 的完整需求资料作为目标来源。

## 最终版本总体方向

最终版本目标是从“调试演示闭环”升级为“可生产运行的复合机器人发货柜系统”。

重点包括：

- 完整任务管理层。
- MES 自动派单和结果回传。
- 完整机器人任务 / RCS 协同层。
- 站点作业层。
- 流程模板层。
- 完整基础数据和权限。
- 全格口硬件接入。
- 完整日志、审计和异常处理。
