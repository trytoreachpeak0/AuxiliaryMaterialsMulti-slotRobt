# 角色与界面术语

## 角色

- 物料员：负责切换到物料员界面、录入可用焊丝批号、将可用焊丝放入发货柜。
- 操作员：负责切换到操作员界面、录入人员和生产信息、归还焊丝并取出可用焊丝。
- OP：操作员的英文缩写。建议仅用于节点 ID 或技术变量，面向用户的中文文案统一使用“操作员”。
- 操作人员：MES 中被查询的人员记录。流程文案中如指用户角色，建议使用“操作员”；如指 MES 人员主数据，可使用“操作人员”。

## 界面

- 物料员界面：物料员执行焊丝存入、开格口等操作的界面。
- 操作员界面：操作员执行焊丝归还、焊丝领用等操作的界面。
- 切换界面：流程开始后的首个步骤，用于进入对应角色界面。

## 提示

- 提示：系统向用户显示的操作指引或异常信息。
- 显示：系统将查询结果或处理结果展示给用户，例如显示操作人员姓名。
- 重新输入：异常分支返回输入节点，让用户修正录入信息。
