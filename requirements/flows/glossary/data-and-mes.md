# 数据与 MES 术语

- MES 数据库：流程中用于查询焊丝规格、操作人员、机台、产品批次、焊丝用量等生产数据的数据源。
- 应用数据库：本系统自己的数据库，用于维护格口业务信息、焊丝归还重量等本地业务数据。
- 工号：操作员身份识别字段，用于查询 MES 中的操作人员。
- 班组：操作员录入的生产组织信息。
- 班次：操作员录入的生产班次信息。
- 操作人员姓名：根据工号从 MES 查询并展示的人员姓名。
- 机台号：操作员录入的设备编号，用于查询对应机台。
- 机台：MES 中与机台号对应的生产设备。
- 产品批次号：机台最近生产的产品批次标识。
- 最近生产的产品批次号：建议替代“最后产品批次号”，用于统一表达机台最新生产批次。
- 产品批号信息：MES 中与产品批次号对应的产品信息。
- 用量差值校验：系统比较剩余待焊芯片数量和预计剩余待焊芯片数量的差值，判断是否满足阈值。
- 500 颗阈值：源流程中用于判断焊丝用量差值是否可接受的阈值。节点 ID 表示 `LE500`，中文文案建议写为“小于等于 500 颗”。
