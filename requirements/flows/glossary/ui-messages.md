# UI 提示文案口径

## 操作指引

- 提示物料员放入对应焊丝并关闭格口门。
- 提示操作员放入对应焊丝并关闭格口门。
- 提示操作员取出对应焊丝并关闭格口门。

## 查询和校验异常

- 无空闲格口：显示无空闲格口的提示。
- 焊丝批号不存在或不合法：显示焊丝批号不存在或不合法的提示。
- 焊丝规格不存在：显示焊丝规格不存在的提示。
- 操作人员不存在：显示不存在该操作人员的提示。
- 机台号不存在：显示不存在该机台号的提示。
- 产品批次号不存在：显示找不到该机台对应的最近生产产品批次号，请到物料间人工归还的提示。
- 产品信息不存在：显示产品信息不存在的提示。
- 焊丝信息不存在：显示焊丝信息不存在的提示。

## 业务异常

- 无匹配焊丝：显示发货柜内没有匹配的焊丝，请到物料间领取的提示。
- 归还重量不存在：显示找不到该焊丝类型的归还重量，请到物料间人工归还的提示。
- 剩余待焊芯片数量不正确：显示剩余待焊芯片数量不正确，重新输入的提示。
- 焊丝归还失败：显示焊丝归还失败的提示。
- 焊丝领用失败：显示焊丝领用失败的提示。

## 成功提示

- 焊丝归还成功：显示焊丝归还成功的提示。
- 焊丝领用成功：显示焊丝领用成功的提示。

## 统一建议

- 同类异常建议统一使用“字段 + 不存在/不合法”的结构。
- “没有找到焊丝规格”建议统一为“焊丝规格不存在”。
- “最后产品批次号”建议统一为“最近生产的产品批次号”。
