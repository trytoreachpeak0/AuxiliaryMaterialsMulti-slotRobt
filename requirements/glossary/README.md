# 焊丝发放流程术语表

本目录基于 `requirements/焊丝发放流程图/` 下 6 个 Mermaid 流程文件重建，未沿用旧 glossary 内容。

## 文件说明

- `source-flow-review.md`：源流程图中的格式问题、错别字和术语不一致点。
- `roles-and-ui.md`：角色、界面和提示类术语。
- `cabinet-and-slots.md`：发货柜、格口、格口门相关术语。
- `material-and-wire.md`：焊丝、批号、规格、重量相关术语。
- `business-operations.md`：存入、归还、领用、开门等业务操作术语。
- `data-and-mes.md`：MES、应用数据库、人员、机台、产品批次相关术语。
- `flow-ids.md`：流程文件、流程标题和建议流程 ID。
- `node-ids.md`：流程节点 ID 的命名约定和已发现的命名问题。
- `ui-messages.md`：流程中出现的用户提示文案口径。

## 统一口径

- 中文术语优先使用完整业务表达，例如“操作员”优先于“OP”。
- “格口”表示柜内物理槽位；“格口门”表示格口对应门体；避免使用非正式简称。
- “可用焊丝”表示物料员存入发货柜后，可被操作员领用的焊丝。
- 流程图内判断节点建议统一使用 Mermaid `{...}` 形状，数据库读写节点使用 `[("...")]` 形状。
