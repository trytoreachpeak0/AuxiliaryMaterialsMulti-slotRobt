# 0.1 版本需求范围

## 1. 版本定位

0.1 版本是调试演示版本，目标是在短周期内证明系统主链路可运行：

```text
焊丝入柜
→ 柜内库存可查询
→ OP 退旧焊丝
→ OP 领取同规格新焊丝
→ 格口状态更新
→ 操作日志可追溯
→ 机器人可手动移动到固定站点
```

0.1 不追求完整平台化能力，优先保证演示稳定、主流程清晰、异常可提示。

## 2. 角色范围

### 2.1 物料员 MH

物料员负责将新焊丝存入发货柜。

0.1 版本需要支持：

- 扫码或录入焊丝批号。
- 查询 MES 获取焊丝规格、物料编码、批次、状态等信息。
- 系统判断是否存在可用空格口。
- 打开指定格口。
- 物料员放入焊丝后确认。
- 系统写入应用数据库库存记录。
- 系统记录操作日志。

### 2.2 操作员 OP

操作员负责退回旧焊丝并领取新焊丝。

0.1 版本需要支持：

- 输入 OP 工号、班组、班次。
- 查询 MES 校验 OP 是否存在。
- 输入旧焊丝批号。
- 查询 MES 获取旧焊丝规格。
- 查询应用数据库，判断柜内是否有同规格新焊丝。
- 输入机台号。
- 查询 MES 校验机台是否存在。
- 查询机台最近产品批次号。
- 输入剩余待焊芯片数量。
- 执行焊线用量核对；若 MES 接口未确认，可先允许 Mock 或人工确认。
- 提交退料；若 MES 写接口未确认，可先记录为 Mock 成功或人工确认。
- 打开回收格口，OP 放入旧焊丝并确认。
- 打开新料格口，OP 取出新焊丝并确认。
- 更新应用数据库库存和格口状态。
- 记录完整操作日志。

### 2.3 维护或管理员

0.1 版本只保留必要维护能力：

- 查看格口状态。
- 查看操作日志。
- 手动测试指定格口开锁。
- 手动设置 Mock 模式或真实接口模式。

不要求实现完整权限矩阵。

## 3. 焊丝存放流程

### 3.1 主流程

```text
开始
→ MH 进入存焊丝界面
→ 输入或扫描焊丝批号
→ 校验批号格式
→ 查询 MES 焊丝信息
→ 判断焊丝是否存在
→ 判断焊丝规格是否存在
→ 查询可用空格口
→ 打开目标格口
→ MH 放入焊丝
→ MH 确认已放入
→ 写应用数据库
→ 更新格口为有料
→ 记录日志
→ 结束
```

### 3.2 最小异常

0.1 版本至少处理：

- 批号为空或格式错误。
- MES 查询不到焊丝批号。
- MES 查询异常。
- 没有可用空格口。
- 开锁失败。
- 操作员未确认放入。

## 4. OP 存废取新流程

### 4.1 主流程

```text
开始
→ OP 进入取换焊丝界面
→ 输入 OP 工号、班组、班次
→ 查询 MES 校验 OP
→ 输入旧焊丝批号
→ 查询 MES 获取旧焊丝规格
→ 查询柜内是否有同规格新焊丝
→ 输入机台号
→ 查询 MES 校验机台
→ 查询机台最近产品批次号
→ 输入剩余待焊芯片数量
→ 调用或模拟焊线用量核对
→ 调用或模拟提交退料
→ 打开回收格口
→ OP 放入旧焊丝并确认
→ 打开新料格口
→ OP 取出新焊丝并确认
→ 更新应用数据库
→ 记录日志
→ 结束
```

### 4.2 最小异常

0.1 版本至少处理：

- OP 不存在。
- 焊丝批号不存在。
- 焊丝状态不允许继续。
- 柜内无同规格新焊丝。
- 机台不存在。
- 最近产品批次号为空或为 N/A。
- 用量核对失败或超差。
- 退料提交失败。
- 回收格口开锁失败。
- 新料格口开锁失败。

## 5. 应用数据库最小范围

0.1 版本只需要支持最小表结构，不要求完整任务模型。

### 5.1 格口表

记录：

- 格口编号。
- 格口显示名称。
- 是否启用。
- 当前业务状态：空闲、有新料、回收占用、异常。
- 是否允许 0.1 版本演示使用。

### 5.2 柜内焊丝表

记录：

- 焊丝批号。
- 焊丝规格。
- 物料编码。
- 主批次。
- 所在格口。
- 库存状态：在柜待发、已取出、已回收。
- 入柜时间。
- 出柜时间。

### 5.3 操作日志表

记录：

- 操作时间。
- 操作人。
- 操作类型。
- 格口编号。
- 焊丝批号。
- 机台号。
- MES 调用结果。
- 格口开锁结果。
- 是否 Mock。
- 错误信息。

## 6. MES 接口最小范围

0.1 版本优先接入现有 `requirements/mes-sql/mes-sql-catalog/items/` 中的 SQL。

### 6.1 必须优先联调

- `mes.operator.get_by_id`
- `mes.wire.get_by_lot_no`
- `mes.eqp.get_by_wire_bonding_eqp_no`
- `mes.product.get_latest_product_lot_by_eqp`

### 6.2 可 Mock 或半联调

- `mes.wire_quota.check_quota`
- `mes.mat_trans.submit_return`

如果 MES 参数含义、返回值或事务口径未确认，0.1 允许：

- 界面显示“当前为模拟提交”。
- 日志记录 `mock = true`。
- 后续版本再切换为真实提交。

## 7. 格口控制最小范围

0.1 版本只要求：

- 支持指定格口开锁。
- 支持开锁成功、失败、超时提示。
- 支持人工确认已放入或已取出。
- 支持读取锁状态；若没有门状态反馈，可使用人工确认作为 0.1 临时方案。
- 至少接入 1 到 2 个真实格口用于演示。
- 其他格口可显示为未配置或禁用。

0.1 不要求：

- 全柜所有格口完整联调。
- 批量开门。
- 物体检测强制确认。
- 完整门状态检测。
- 完整异常锁定策略。

## 8. 手动控车最小范围

0.1 版本不做完整任务层，只做手动移动会话。

### 8.1 功能

- 界面选择目标站点。
- 系统执行移动前检查。
- 调用 RCS 下发目标站点。
- 显示移动中状态。
- 轮询或接收 RCS 到站状态。
- 到站后显示当前站点。
- 到站后允许继续执行 MH 或 OP 流程。
- 记录移动日志。

### 8.2 最小移动状态

移动状态只需要：

- `Idle`：空闲。
- `Sending`：正在下发。
- `Moving`：移动中。
- `Arrived`：已到站。
- `Failed`：移动失败。
- `Timeout`：到站超时。

### 8.3 移动前检查

至少检查：

- 当前无格口正在开锁。
- 当前无 OP/MH 正在进行存取确认。
- 演示格口处于可移动状态。
- RCS 通信正常或处于 Mock 模式。

## 9. 界面范围

0.1 版本需要的界面：

- MH 存焊丝界面。
- OP 存废取新界面。
- 格口状态展示。
- 手动控车界面。
- 操作日志查看或导出。
- Mock/真实接口模式提示。

0.1 不要求：

- 完整管理后台。
- 用户权限配置页面。
- 流程模板配置页面。
- MES 任务列表页面。
- 多任务监控大屏。

## 10. 0.1 版本不做项

以下全部放入后续版本：

- MES 自动获取任务。
- 人工创建完整配送任务。
- 内部统一任务状态机。
- 完整机器人任务层。
- 完整站点作业会话。
- 完整流程模板层。
- 多点配送。
- 多点收料。
- 自动回充。
- 低电量任务中断和恢复。
- 全角色权限矩阵。
- 全量异常回传 MES。
- 完整审计报表。
