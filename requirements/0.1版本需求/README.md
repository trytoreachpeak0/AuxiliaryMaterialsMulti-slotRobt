# 0.1 版本需求

## 版本目标

0.1 版本用于 1.5 周内调试和演示，目标不是完整一期系统，而是先交付一个能跑通的最小闭环：

- 焊丝存放流程完整可操作。
- OP 存废焊丝并领取新焊丝主流程可操作。
- 发货柜至少 1 到 2 个格口可真实开锁或模拟开锁。
- 通过界面手动控制机器人去固定站点。
- 到站后允许继续执行焊丝存取操作。
- 关键 MES 查询可联调；MES 写操作未确认时允许先用 Mock 或人工确认占位。

## 0.1 版本边界

### 包含

- 物料员 MH 存放焊丝。
- 操作员 OP 存废焊丝、取新焊丝。
- 焊丝批号、规格、机台、OP 的关键校验。
- 应用数据库最小库存记录。
- 格口开锁、格口占用、操作日志。
- 手动控车：选择目标站点、下发 RCS、查询到站状态。
- 移动前最小安全检查：格口未关闭或正在开锁时禁止移动。

### 不包含

- MES 自动派单。
- 完整任务管理层。
- 任务池、任务排队、任务优先级。
- 通用流程模板引擎。
- 多点配送、多点收料。
- 自动回充和低电量任务恢复。
- 全格口完整硬件验收。
- 多车、多柜、RCS 调度策略。
