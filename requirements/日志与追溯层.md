# 日志与追溯层 Logging and Traceability Layer

## 1. 文档说明

### 1.1 文档目的

日志与追溯层负责统一记录复合机器人发货柜系统中的任务、OP 操作、扫码、开锁、MES 交互、RCS 交互、异常、人工放行、配置变更等关键过程。

日志与追溯层应支持问题排查、责任追溯、接口对账、异常复盘、物料流向追踪和配置变更审计。

本文档用于说明日志与追溯层在需求阶段需要具备的记录对象、记录范围、查询能力、保留策略和审计要求，不描述具体日志组件、数据库表结构或存储实现。

### 1.2 职责边界

日志与追溯层负责“发生了什么、谁做的、什么时候做的、结果是什么、关联到哪个任务和物料”。

简单来说：

- 各业务层负责执行业务动作。
- 日志与追溯层负责记录业务动作和关键状态变化。
- 界面层负责展示可查询的日志和追溯结果。
- 管理员、主管和维护人员按权限查看日志。

日志与追溯层不直接改变任务状态，不直接重试接口，不直接开格口。日志只记录事实和结果，不替代业务处理。

### 1.3 一期建设原则

一期应优先保证关键业务闭环可追溯。

一期至少应覆盖：

- 任务生命周期日志。
- OP 操作日志。
- 扫码日志。
- 开锁和格口状态日志。
- MES 请求、响应和回传日志。
- RCS 下发、到站和异常日志。
- 异常发生、处理和关闭日志。
- 人工放行日志。
- 基础数据和流程模板配置变更日志。

## 2. 追溯主线

### 2.1 按任务追溯

按任务追溯应能查看一个任务从创建到完成或关闭的完整过程。

至少包括：

- 任务创建来源。
- MES 任务编号，如果有。
- 任务明细。
- 绑定流程模板版本。
- 机器人移动过程。
- 到站作业过程。
- OP 操作过程。
- 扫码记录。
- 格口开锁记录。
- MES 校验和回传记录。
- 异常和人工放行记录。
- 任务完成或关闭结果。

### 2.2 按物料追溯

按物料追溯应能查看物料在系统中的流转过程。

至少包括：

- 物料编码。
- 物料名称。
- 批次号。
- 工单号。
- 来源任务。
- 存入格口。
- 取出格口。
- 存货 OP。
- 取货 OP。
- 扫码记录。
- MES 回传结果。

### 2.3 按格口追溯

按格口追溯应能查看某个格口在一段时间内的使用过程。

至少包括：

- 格口编号。
- 所属发货柜。
- 占用任务。
- 开锁记录。
- 传感器状态变化。
- 锁状态或门状态变化。
- 格口启用、禁用和异常记录。
- 维护或配置变更记录。

### 2.4 按 OP 追溯

按 OP 追溯应能查看某个 OP 的业务操作记录。

至少包括：

- OP 编号。
- OP 名称。
- 操作任务。
- 操作站点。
- 操作格口。
- 操作类型。
- 扫码内容。
- 操作结果。
- 是否代操作。
- 是否发生授权放行。

### 2.5 按接口追溯

按接口追溯应能查看 MES 和 RCS 的请求、响应和业务影响。

至少包括：

- 接口类型。
- 请求时间。
- 响应时间。
- 请求摘要。
- 响应摘要。
- 返回状态。
- 关联任务。
- 失败原因。
- 重试记录。

## 3. 日志类型

### 3.1 任务日志

任务日志记录任务生命周期变化。

至少记录：

- 任务创建。
- 任务解析。
- 模板绑定。
- 任务开始。
- 任务暂停。
- 任务恢复。
- 任务明细完成。
- 任务完成。
- 任务取消。
- 任务异常关闭。

任务日志应记录状态变化前后的状态和触发来源。

### 3.2 OP 操作日志

OP 操作日志记录现场人员的业务动作。

至少记录：

- 登录或身份认证。
- 装货确认。
- 取货确认。
- 人工确认。
- 异常申报。
- 主管或管理员放行。
- 任务关闭操作。

OP 操作日志应记录 OP 编号、OP 名称、角色、站点、任务、格口、操作时间和操作结果。

### 3.3 扫码日志

扫码日志记录 OP 在站点作业过程中的扫码行为。

至少记录：

- 扫码时间。
- 扫码人。
- 条码内容。
- 条码类型。
- 关联任务。
- 关联物料。
- 关联格口。
- 校验结果。
- 失败原因。

扫码失败也应记录，便于排查错料、错批次或重复扫码问题。

### 3.4 开锁日志

开锁日志记录格口开锁请求、执行和反馈结果。

至少记录：

- 开锁请求时间。
- 请求来源。
- 操作人。
- 关联任务。
- 格口编号。
- 锁控板编号。
- 指令编号。
- 指令发送结果。
- 硬件反馈结果。
- 开锁失败原因。

开锁日志应能区分业务拒绝、硬件失败和反馈超时。

### 3.5 MES 日志

MES 日志记录与 MES 的任务、校验、完成和异常交互。

至少记录：

- MES 任务获取。
- 任务解析结果。
- 装货前校验。
- 取货前校验。
- 完成回传。
- 异常回传。
- 回传重试。

MES 日志应能关联 MES 任务编号、系统任务编号、OP 信息和物料明细。

### 3.6 RCS 日志

RCS 日志记录机器人移动相关交互。

至少记录：

- 移动任务创建。
- 目标站点下发。
- RCS 返回结果。
- 到站反馈。
- 移动失败。
- 到站超时。
- 低电量回充。
- 充电完成返回驻点。

RCS 日志应能关联机器人编号、RCS 设备编码、目标站点和业务任务。

### 3.7 异常日志

异常日志记录系统中的业务异常、硬件异常、接口异常和人工处理过程。

至少记录：

- 异常编号。
- 异常类型。
- 异常等级。
- 异常来源。
- 关联任务。
- 关联格口。
- 异常描述。
- 发生时间。
- 处理人。
- 处理方式。
- 关闭时间。

异常解除或关闭时，应记录处理结论。

### 3.8 人工放行日志

人工放行日志记录主管或管理员绕过部分异常或校验限制的授权动作。

至少记录：

- 放行类型。
- 放行原因。
- 被放行的任务、格口或操作。
- 申请人。
- 授权人。
- 授权时间。
- 放行前状态。
- 放行后结果。

人工放行属于高风险操作，必须可审计。

### 3.9 配置变更日志

配置变更日志记录基础数据、流程模板、权限、接口参数和硬件映射的变更。

至少记录：

- 配置对象。
- 变更类型。
- 变更前内容。
- 变更后内容。
- 操作人。
- 操作时间。
- 变更原因。
- 生效时间。

## 4. 日志字段要求

### 4.1 通用字段

所有关键日志建议包含：

- 日志编号。
- 日志类型。
- 发生时间。
- 关联任务编号。
- 关联任务明细编号，如果有。
- 关联机器人编号。
- 关联发货柜编号。
- 关联格口编号，如果有。
- 关联站点编号，如果有。
- 操作人，如果有。
- 操作来源。
- 操作结果。
- 失败原因，如果有。

### 4.2 业务关联字段

用于业务追溯的日志应尽量包含：

- MES 任务编号。
- 工单号。
- 物料编码。
- 物料名称。
- 批次号。
- 数量。
- 单位。
- OP 编号。
- OP 名称。
- 流程模板编号。
- 流程模板版本。

### 4.3 技术诊断字段

用于接口和硬件排查的日志应包含：

- 请求编号。
- 指令编号。
- 外部系统返回码。
- 外部系统返回消息。
- 通信耗时。
- 重试次数。
- 锁控板编号。
- 点位地址。
- RCS 任务编号。

## 5. 查询能力

### 5.1 查询条件

日志查询应支持按以下条件筛选：

- 时间范围。
- 任务编号。
- MES 任务编号。
- 机器人编号。
- 发货柜编号。
- 格口编号。
- 站点编号。
- OP 编号。
- 物料编码。
- 工单号。
- 日志类型。
- 异常类型。
- 操作结果。

### 5.2 查询视图

建议提供以下追溯视图：

- 任务全过程追溯。
- 物料流向追溯。
- 格口使用追溯。
- OP 操作追溯。
- MES 接口追溯。
- RCS 移动追溯。
- 异常处理追溯。
- 配置变更追溯。

### 5.3 导出能力

系统应支持按权限导出日志查询结果。

导出内容应受权限控制，涉及敏感信息时应脱敏或限制导出范围。

## 6. 保留与审计

### 6.1 日志保留

系统应明确不同日志类型的保留周期。

建议关键业务日志、MES 回传日志、人工放行日志和配置变更日志长期保留。普通调试日志可按容量或时间滚动清理。

### 6.2 防篡改要求

关键追溯日志不应被普通用户修改或删除。

如确需修正，应通过补充记录方式说明修正原因、修正人和修正时间，不应覆盖原始日志。

### 6.3 权限控制

日志查看和导出应受角色权限控制。

普通 OP 只应查看与本人当前作业相关的提示和结果；主管、管理员和维护人员可按权限查看更大范围日志。

## 7. 异常与告警联动

日志与追溯层应与异常处理能力联动。

当发生以下情况时，应生成异常日志并可触发告警：

- MES 校验失败或接口异常。
- RCS 移动失败或到站超时。
- 锁控板通信异常。
- 开锁失败或状态不一致。
- 格口未关闭或安全联锁失败。
- OP 越权尝试。
- 人工放行。
- 高风险配置变更。

异常日志应能关联后续处理动作，形成完整闭环。
